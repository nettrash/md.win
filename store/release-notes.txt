Version 1.6

FORMATTING
• A Format menu with the shortcuts every md app now shares: Bold (Ctrl+B), Italic (Ctrl+I), Code (Ctrl+Shift+C), Strikethrough (Ctrl+Shift+X), Link (Ctrl+K), Heading 1 to 6 (Ctrl+Alt+1 to 6), Bullet List (Ctrl+Shift+L), Task List (Ctrl+Shift+T), Quote (Ctrl+Shift+Q), Indent and Outdent (Ctrl+] and Ctrl+[).
• Each one toggles, works on every line you have selected, and is a single undo step.
• Typing *, _, a backtick or $ with text selected wraps the selection instead of replacing it. It is a switch under Edit, Typing, and on by default.
• On keyboards where AltGr and a digit types a character, AltGr still types it; the left Ctrl+Alt is the heading shortcut.

E-BOOKS
• An EPUB now carries the author, language, date, description and series from the document's front matter, so it arrives in a reader's library properly labelled.
• A cover: line in the front matter puts that image on the book: a picture beside the document, a web image, or one pasted inline. If it cannot be read, the book is written without one.

DIAGRAMS
• Large PlantUML diagrams draw. A diagram wider or taller than 4096 pixels no longer stops at "Diagram too large".
