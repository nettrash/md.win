md is a Markdown editor and live previewer for Windows 11 (build 22000 or later, x64 and ARM64). Version 1.6.0.0, after 1.0 and 1.5; the number is shared across md's editions.

ACCESS: No account, sign-in or purchases, so no test credentials exist. Everything works at launch; File, Examples ships nine sample documents and a sample book.

ONE-MINUTE WALKTHROUGH
1. Launch; an untitled window opens. File, Examples: Math, Diagrams and Plots show LaTeX, chemistry, Mermaid, Graphviz, PlantUML and charts, drawn offline.
2. View, Edit / Split / Preview (Ctrl+1 / 2 / 3); View, Zen Mode (Ctrl+Shift+Enter; Esc leaves).
3. File, Export, PDF writes real pages; File, Print (Ctrl+P) previews inside the window.
4. New in 1.6: select a word, Format, Bold (Ctrl+B). Front matter author: and cover: lines label an exported EPUB.
5. File, Examples, Example Book: choose a folder; the book window opens.

NETWORK: No servers of ours; no analytics, advertising or telemetry. Network use is only WebView2 fetching an image a user's own document references by URL, and EPUB export fetching the https cover named in front matter (at most 20 MB, https redirects only).

CODE: The engines (KaTeX with mhchem, Mermaid, Graphviz via Viz.js, PlantUML, highlight.js) are open-source JavaScript bundled in the package and served to WebView2 locally. Nothing is downloaded or updated at run time; WebView2 is Windows 11's own.

CAPABILITIES: runFullTrust only. A WinUI 3 desktop app using the Windows file pickers, drag and drop, file associations and WebView2; it reads and writes only the documents the user opens or saves. No camera, microphone or location.

FILE TYPES: Owner of .md, .markdown and eight other Markdown spellings; alternate handler for .txt, .text, PlantUML, .gv and .textpack files. A .textbundle folder opens via File, Open TextBundle Folder.

Encryption: none. Regional differences: none. No data is collected; privacy policy: https://nettrash.me/msstore/md/privacy.html. The source is public.
